# VideoRec 使用说明书

行为学录制条件控制工具：USB 摄像头接入、参考帧虚影对齐、光照一致性量化、鼠标区域触发录制、快捷键行为备注。

---

## 0. 四路版说明（D:\video_rec4）

`D:\video_rec4` 是四路版（原版 `D:\video_rec` 保持不动），**一个窗口同时预览/录制最多 4 路摄像头**（2×2 布局），一次录 4 只小鼠提高效率。

**与单路版的差异：**
- 启动时自动检测并打开所有摄像头（最多 4 路，按检测顺序填入 Cam 1-4 槽位）
- **点击某路预览 = 选中该路**（橙色边框高亮），右侧面板（参考帧/虚影/ORB/光照分析/画面参数）只作用于当前选中路
- **● 开始录制 = 全部已连接路同时开录**，文件名 `<项目名>_CamN_<时间戳>.avi`（N = 槽位号，与预览标签、meta.json 的 cam 字段一一对应，不会错位）；停止后汇总各路统计
- **动物信息面板**（右侧）：每路一个输入框，填一次整个 session 记住（存 `animal_info.json`），录制时自动写入每路 meta.json 的 `animal` 字段；某路未填时录制开始给黄色警告，**不阻止录制**（想先录就录，下段补填）
- 网格开关作用于全部四路
- F1-F9 行为备注打到**当前选中路**（切到对应路再打点）
- 鼠标区域触发 = 触发全部路同时录制
- 摄像头参数（分辨率/帧率/曝光等）切换路时自动跟随当前路；分辨率/帧率在录制中不可改

**启动：**
```
cd D:\video_rec4
python main.py
```
或双击 `D:\video_rec4\VideoRec.bat`（bat 里路径请改为 video_rec4）。

**提示：** 只有 1 个摄像头时其余槽位显示"无画面"，功能与单路版一致。

## 1. 安装与启动

### 1.1 源码运行（开发机）
```
cd D:\video_rec
python main.py
```
或双击 `VideoRec.bat`。

### 1.2 便携版（打包 exe，移植到别的电脑）
1. 把 `VideoRec_便携版.zip` 拷贝到目标电脑，解压到任意目录（如 `D:\VideoRec`）
2. 双击 `VideoRec.exe` 启动
3. **项目数据（projects/）自动创建在 exe 旁边**，换电脑不丢数据

**目标电脑要求：**
- Windows 10/11（64 位）
- USB 摄像头（UVC 标准免驱；杂牌摄像头请先装官方驱动）
- 摄像头插 USB3.0 口更稳（USB2.0 跑 640×480@30 也够，MJPG 约 9MB/s）

**权限提示：** 如果要用「鼠标区域触发」联动其他软件（如光纤记录），VideoRec 和那个软件**都要以管理员身份运行**，否则全局鼠标钩子收不到点击。

## 3. 快速上手（5 分钟流程）

1. **插上摄像头** → 启动 VideoRec，自动连接第一个摄像头（状态栏显示 `摄像头 #0 已连接 640x480@30fps`）
2. **新建项目** → 填项目名、实验信息、装置、环境备注，选保存路径（会自动填默认路径）
3. **摆好装置**（笼子、灯光、相机角度）→ 点「📌 存当前帧为参考」
4. **检查一致性**：每次实验前调整装置，看「光照判定」是否为 OK、位置偏差是否小
5. **设置触发区域**（可选）→ 主界面「🎯 触发区域设置...」→ 拖画框选 → 勾选「启用」
6. **点「● 开始录制」** → 实验 → 点「■ 停止录制」
7. 到项目文件夹拿数据：`recordings/rec_时间戳/` 下是视频 + 时间戳 + 备注

## 5. 摄像头与画面参数

点主界面 **「🎛 画面参数...」** 打开独立窗口：

### 5.1 画幅与帧率
- 分辨率：640×480 ～ 1920×1080
- 帧率：15 / 25 / 30 / 60
- **修改立即生效**（自动重开摄像头）
- 「检测支持的分辨率」：列出摄像头真实能力

### 5.2 画面参数滑杆
亮度 / 对比度 / 饱和度 / 色相 / 伽马 / 曝光 / 增益 / 白平衡 等（随摄像头支持情况而定）。
- 滑杆**拖动即生效**，边看预览边调
- 「应用参数」：全部应用一次
- 「恢复自动」：曝光/白平衡恢复自动

### 5.3 超出硬件能力
如果请求的分辨率/帧率摄像头不支持，会自动回退到硬件实际值并弹窗提示（附带宽估算）。

### 5.4 画面参数保存 / 加载
调好的参数不用每次重调：

- **「💾 保存参数」**：把当前分辨率、帧率、所有滑杆值存成 `camera_params.json`
  - 已打开项目 → 存到**项目目录**（每个项目一套独立参数）
  - 未打开项目 → 存到**程序目录**（exe 旁边），作为全局默认
- **「📂 加载参数」**：一键恢复上次保存的参数；若分辨率/帧率有变化，会自动重开摄像头
- **自动恢复**：每次连接摄像头时自动加载已保存参数（项目参数优先，回退全局默认）——换电脑、重插摄像头都不用手动重调
- 保存位置显示在对话框底部，鼠标悬停可看完整路径

## 6. 参考帧与一致性控制

这是本工具的核心功能：**保证每次实验的拍摄条件一致**，排除光照/位置变量。

### 6.1 建立参考（第一天/第一次实验）
1. 摆好装置，让小鼠待在笼子里（或空笼）
2. 点「📌 存当前帧为参考」→ 保存画面 + 摄像头参数快照

### 6.2 后续每次实验
- **位置对齐**（ORB 自动对齐，默认开）：每 150ms 算一次，检测相机是否被碰歪
  - 绿色 = 位置正常，橙色 = 低置信度，红色 = 对不上
- **光照量化**：亮度、对比度、过曝/欠曝、模糊度 + 与参考的差值
  - 判定：OK / 注意 / 调整（鼠标悬停看建议）
- **虚影叠加**：当前画面半透明叠在参考帧上，一眼看出偏差
- **网格**：辅助判断位置偏移
- **ORB 关注区域**：框选装置/背景区域，只在那里找特征点，避开小鼠活动干扰

### 6.3 参考帧保存内容
- `reference.png`：参考画面
- `reference_camera.json`：当时摄像头参数（后续可对照）

## 7. 鼠标区域触发录制（联动光纤记录等）

把录制动作绑定到屏幕某个区域：实验者点那个区域 → 自动开始/停止录制，可设延时。

### 7.1 设置（主界面「🎯 触发区域设置...」）
1. 「🎯 拖画框选区域（全屏）」→ 屏幕变暗，拖画一个框 → 松手确定
2. 也可手动填 X / Y / 宽 / 高
3. 「触发延时」：点击后延迟多久开始录制（0–5000ms）
4. 勾选「显示触发区」→ 屏幕上显示半透明红框（**点击穿透**，不影响其他软件操作；主窗口最小化也保持显示）

### 7.2 使用
1. 主界面勾选「启用」→ 状态栏显示 `✅ 监听中：点击屏幕 (x,y) WxH 区域...`
2. 实验时点击触发区 → 红框闪黄提示 → 自动开始录制
3. 再点一次 → 停止录制
4. 不想要了 → 取消勾选「启用」

> 触发区域配置会**自动保存到项目**，下次打开项目自动恢复。

## 8. 录制备注（行为打点）

录制中给行为事件打时间戳备注：

1. 在主界面备注区填好内容（默认：嗅探 / 理毛 / 爬跨 / 攻击 / 其他），**一列两个**，F1、F2 并排
2. 录制中：
   - 按 **F1–F9** 快捷键，或
   - 点对应的 F 按钮
3. 停止录制后生成 `notes.csv`：

```
note_idx,frame,time_s,content
1,29,1.002,嗅探
2,45,1.550,理毛
```

- `frame` = 视频帧号，`time_s` = 录制开始后的秒数
- 用「+ 添加 / - 删除」增删备注项（F 键编号自动跟随）

## 9. 录制与输出

### 9.1 录制
- 点「● 开始录制」（红色）→ 变为「■ 停止录制」（绿色）
- **录制在独立线程进行**：读帧、MJPG 编码、写盘都不占用界面，界面卡顿不掉帧
- 录制中界面自动暂停光照比对（省 CPU）

### 9.2 掉帧保护
- 录制开始约 2 秒后自动检测一次实际帧率
- 实际 < 目标 80% → 弹窗警告「正在掉帧！」
- 停止时再次统计，丢帧 > 1% 弹窗提示
- 遇到掉帧：降分辨率（720→480）或降帧率（30→15）

### 9.3 输出文件（`recordings/rec_YYYYMMDD_HHMMSS/`）
| 文件 | 内容 |
|---|---|
| `rec_*.avi` | MJPG 编码视频 |
| `rec_*.timestamps.csv` | 每帧时间戳：`frame_idx, timestamp_s, monotonic_s` |
| `rec_*.notes.csv` | 行为备注（见上节） |
| `rec_*.meta.json` | 元数据（分辨率、帧率、摄像头参数等） |

## 10. 常见问题（FAQ）

**Q：提示「参数超出硬件能力」？**
A：摄像头不支持所选分辨率/帧率，已自动回退。换摄像头或降参数。

**Q：提示「正在掉帧」？**
A：降低分辨率/帧率；确认摄像头插在 USB3.0 口；关闭占用 CPU 的大软件。

**Q：触发启用失败（pynput 不可用）？**
A：以管理员身份运行 VideoRec。

**Q：触发区半透明框不见了？**
A：在「触发区域设置...」里勾选「显示触发区」。

**Q：录完找不到文件？**
A：在项目目录的 `recordings/` 下；打开项目后状态栏会显示录像路径。

**Q：换了电脑，之前的项目能用吗？**
A：把整个 `projects/` 文件夹（exe 旁边）拷过去即可；或「打开项目...」指向原目录。

**Q：怎么确认没掉帧？**
A：停止录制后看状态栏：`录制完成: N 帧, Xs, 实际帧率 Y, 丢帧 Z`。Z=0 最理想。
